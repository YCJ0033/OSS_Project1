# Vertical Shooter (S/W engineering proj 1)

화면 아래쪽 플레이어 비행기를 좌우로 움직이며 총알을 쏘아, 위에서 내려오는 적을 맞히는 종스크롤 슈팅 게임.

> 이 README 는 스타터에 들어 있던 것입니다. 제출 전에 아래 **[학생 작성]** 부분을 직접 채우세요.

## 실행 방법

- Python 3.10–3.13, pygame 2.x
  - Python 3.14 에서는 pygame 2.6.1 이 설치되지 않으니, 3.10–3.13 중 하나를 사용할 것.

```bash
pip install pygame
python main.py
```

## 조작

| 키 | 동작 |
|---|---|
| ← / → | 좌우 이동 |
| Space | 시작 화면에서 게임 시작 / 게임 중 총알 발사 |
| R | 게임 오버 후 다시 시작 |
| Esc | 종료 (시작 화면에서도) |

## 파일 구성

| 파일 | 내용 |
|---|---|
| `main.py` | 게임 루프 — 입력 처리, 갱신, 그리기, 점수·생명·게임 오버 |
| `entities.py` | 그림 불러오기(`load_frame`), 배경(`Background`), 스프라이트 클래스 — `Player`, `Bullet`, `Enemy` |
| `settings.py` | 화면 크기·속도·색 같은 상수 |
| `assets/` | 그림 — ansimuz CC0 픽셀 아트 (출처: `assets/CREDITS.md`) |
| `AI_USAGE.md` | 생성형 AI 사용 기록 |

## 구현한 기능 [학생 작성]

- [x] **F1 플레이어 이동**
  - 방향키를 이용하여 플레이어 비행기를 좌우로 이동할 수 있도록 구현했습니다.
  - 플레이어가 화면 바깥으로 벗어나지 않도록 이동 범위를 제한했습니다.

- [x] **F2 총알 발사**
  - 게임 진행 중 SPACE 키를 누르면 플레이어 비행기에서 총알이 발사됩니다.
  - 화면 밖으로 이동한 총알은 자동으로 제거되며, 게임 오버 상태에서는 발사되지 않도록 구현했습니다.

- [x] **F3 적 명중 및 점수**
  - 총알과 적 비행기의 충돌을 판정하여 명중 시 적과 총알이 제거되도록 구현했습니다.
  - 적을 처치할 때마다 10점씩 점수가 증가하며, 현재 점수가 게임 화면에 표시됩니다.

- [x] **F4 피격 및 게임 오버**
  - 플레이어가 적과 충돌하거나 적이 화면 아래로 지나가면 생명이 감소하도록 구현했습니다.
  - 생명이 0이 되면 게임이 종료되고, 게임 오버 화면과 최종 점수가 표시됩니다.

- [x] **F5 게임 재시작 및 최고 점수 저장**
  - 게임 오버 상태에서 R키를 누르면 점수와 생명이 초기화되어 새 게임을 시작할 수 있습니다.
  - 최고 점수를 파일에 저장하고, 프로그램을 종료했다가 다시 실행해도 기존 기록이 유지되도록 구현했습니다.
